# STEP11C Teacher Training on BAIR VideoMAE Tokens

## 1. Goal

Step 11C trains a tiny full-token TeacherWorldModel smoke on BAIR Robot Pushing small VideoMAE token shards generated by Step 11B. It uses the train token shards for optimization and the test token shards for evaluation.

## 2. Cloud Server Decision

No cloud server was needed for this stage. Step 11C does not run the VideoMAE encoder; it only reads existing token shards from disk and trains a small TeacherWorldModel. A cloud 4090 / 48GB server is only recommended if larger BAIR shard sets, larger teachers, more seeds, or lower-memory GPUs hit OOM.
